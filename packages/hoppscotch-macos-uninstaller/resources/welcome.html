ℹ️ Why does the button say "Install"? macOS always labels this button Install — even for uninstallers. It is a system label that cannot be renamed. Clicking Install will permanently remove Hoppscotch from this Mac. Nothing is being installed.

Remove Hoppscotch from this Mac

Clicking Install will completely remove Hoppscotch from your Mac, including:

  • The Hoppscotch.app bundle from /Applications
  • Application support data in ~/Library/Application Support/io.hoppscotch.desktop
  • Log files in ~/Library/Logs/io.hoppscotch.desktop
  • Caches in ~/Library/Caches/io.hoppscotch.desktop
  • WebKit storage in ~/Library/WebKit/io.hoppscotch.desktop
  • Saved state and preferences
⚠️ This action cannot be undone. All local workspaces, collections, and settings stored by Hoppscotch will be permanently deleted.
